## MODIFIED Requirements

### Requirement: モードの許可ツールを適用する

システムは選択中のモードに定義されたツールだけを pi で有効にすることを MUST とする。すべてのモードは、pi-memory が登録する記憶用ツールを許可ツールに含めなければならない。

#### Scenario: アドバイスモードで起動する
- **WHEN** 新しいセッションが既定のアドバイスモードで始まる
- **THEN** `read`、`grep`、`find`、`ls` と記憶用ツールのみが有効になり、`bash`、`edit`、`write` は有効にならない

#### Scenario: モードを確定する
- **WHEN** 利用者が `/mode` で別のモードを確定する
- **THEN** 選択したモードの許可ツールが次の応答前に有効になり、記憶用ツールは引き続き有効である

#### Scenario: モード選択をキャンセルする
- **WHEN** 利用者が `/mode` の選択をキャンセルする
- **THEN** 現在のモードと許可ツールは変わらない

#### Scenario: セッションを開始し直す
- **WHEN** 新しいセッションが始まる
- **THEN** 既定モードとその許可ツールへ戻る
