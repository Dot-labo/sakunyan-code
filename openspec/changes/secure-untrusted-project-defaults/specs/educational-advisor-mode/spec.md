## MODIFIED Requirements

### Requirement: 調査用ツールを利用できる

MUST: アドバイスモードは、ファイルの読み取り、検索、一覧表示による調査をサポートし、コマンドの実行が必要な場合は、その意味と手順を説明して利用者本人に実行してもらうものとする。

#### Scenario: ファイルを調査して原因を説明する

- **WHEN** ユーザーが何かが失敗する理由を尋ね、関連ファイルから原因を調査できるとき
- **THEN** エージェントは`read`、`grep`、`find`、`ls`を使って関連ファイルを調べてから、原因を説明しなければならない
- **AND** 調査のために`bash`を実行してはならない

#### Scenario: コマンドの実行が必要になる

- **WHEN** エラーの再現、環境確認、テストなどにコマンドの実行が必要なとき
- **THEN** エージェントはコマンドの目的と起こることを子どもにも分かる言葉で説明しなければならない
- **AND** 利用者本人が実行できる正確なコマンドと、その結果を伝える方法を案内しなければならない
- **AND** アドバイスモードのエージェント自身がそのコマンドを実行してはならない
