## Why

sakunyanは子どもや初心者が任意のプロジェクトで起動するため、リポジトリ内の指示を自動でモデルへ渡したり、既定状態でモデルへ無制限の`bash`を与えたりすると、利用者が理解しないままローカル環境の情報参照や状態変更を誘導されるおそれがある。起動時のアドバイスモードを安全な既定値へ統一し、不要な英語のプロジェクト信頼確認も表示しないようにする。

## What Changes

- 起動時のアドバイスモードでは、piを「プロジェクトを信頼しない」設定で起動し、`Trust project folder?`を表示しない
- `.pi`設定、プロジェクト拡張、Skills、プロンプトテンプレート、`AGENTS.md`や`CLAUDE.md`などのコンテキストファイルを自動読み込みしない
- アドバイスモードのツールを`read`、`grep`、`find`、`ls`に限定し、`bash`、`write`、`edit`を有効化しない
- コマンドが必要な場合は、意味と実行方法を説明して子ども本人に実行してもらう
- READMEの機能説明と安全上の境界を実際の既定動作へ合わせる
- 未信頼プロジェクトのリソース抑制、信頼確認の非表示、ツール許可リスト、アドバイス方針を回帰テストで確認する
- モード選択基盤はIssue #4、明示的な確認後に広い実行能力を与える問題解決モードはIssue #10で別途扱う

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `fixed-pi-runtime`: プロジェクトを信頼しない起動設定、コンテキストファイルを含むプロジェクトリソースの抑制、アドバイスモードの読み取り専用ツール許可リストへ要求を変更する
- `educational-advisor-mode`: アドバイスモードではコマンドを自動実行せず、意味と手順を説明して利用者本人に実行してもらう要求へ変更する

## Impact

- `src/cli.ts`のpi起動引数と起動時のツール許可リスト
- `src/educational-prompt.ts`の調査・コマンド案内方針
- `test/cli.test.js`の起動引数、未信頼プロジェクト、教育プロンプトに関する回帰テスト
- READMEの機能説明、安全上の注意、利用可能な操作
- `fixed-pi-runtime`と`educational-advisor-mode` capabilityの要求
