## ADDED Requirements

### Requirement: 有効なAPIキーの状態を接続確認行に表示する

TUIは、現在有効になっているAPIキーの状態を、常時表示される接続確認結果の行に追加することをMUSTとする。表示には、絵文字と有効期限の残り時間（あとN日・あとN時間・あとN分）を簡潔に示し、利用残量（コスト）は残量バーとパーセントで示さなければならない。APIキーそのものや秘密情報を表示してはならない。

#### Scenario: 有効期限と利用残量を表示する

- **WHEN** 現在有効なAPIキーの有効期限と利用上限の情報を取得できるとき
- **THEN** 接続確認結果の行は有効期限を絵文字と残り時間だけで簡潔に表示しなければならない
- **AND** 期限までの残り時間を、24時間以上では日、24時間未満では時間、1時間未満では分の単位で表示しなければならない
- **AND** 同じ行は利用残量をバー表示とパーセント表示の両方で表示しなければならない
- **AND** パーセントは0%以上100%以下の範囲で、利用上限に対する残量を表さなければならない

#### Scenario: 有効期限が近いキーを表示する

- **WHEN** 現在有効なAPIキーの有効期限が近づいているとき
- **THEN** 接続確認結果の行は通常時と区別できる色または注意表示で有効期限を示さなければならない
- **AND** 有効期限を日・時間・分のうち適切な単位の残り時間で確認できなければならない

#### Scenario: 利用残量が少ないキーを表示する

- **WHEN** 利用残量が少なくなっているとき
- **THEN** 接続確認結果の行の残量バーとパーセント表示は通常時と区別できる色または注意表示でなければならない
- **AND** 表示は残量が少ないことを利用者がすぐに判断できなければならない

#### Scenario: キー情報を取得できない

- **WHEN** 現在有効なAPIキーがない、または有効期限・利用残量を取得できないとき
- **THEN** 接続確認結果の行は取得できていない情報について推測した値や古い値を表示してはならない
- **AND** 接続確認結果の行は「取得できません」など、情報が利用できない状態をわかりやすく表示しなければならない
