# 教室共通のルール仕様

## Purpose

教室で主に使うツール・ライブラリの方針を、パッケージが提供する固定の指示として持ち、全ての応答モードの案内に反映する。パッケージを更新すれば、全てのパソコンで新しい方針になる。

## Requirements

### Requirement: ルールはパッケージが提供する固定の内容にする

sakunyanは、教室共通のルールを、パッケージの中（`src/classroom-rules.ts` の定数）に持たなければならない。利用者のパソコンのファイル、環境変数、引数から、ルールの内容を読み込んではならない。ルールの内容を変えるときは、パッケージの中の内容を直し、新しいバージョンとして公開する。

#### Scenario: パッケージを更新する

- **WHEN** ルールの内容を直した新しいバージョンのsakunyanへ更新したとき
- **THEN** そのパソコンに何が保存されているかに関係なく、次の起動から、新しい内容をsystem promptへ加えなければならない

#### Scenario: 作業フォルダにファイルがある

- **WHEN** 作業フォルダに `CLASSROOM.md` や `AGENTS.md` があるとき
- **THEN** その内容をsystem promptへ加えてはならない

### Requirement: 利用者のパソコンにルールのファイルを作らない・読まない

sakunyanは、sakunyan専用フォルダ（`~/.sakunyan/`）に、ルールのファイルを作ってはならない。以前のバージョン（0.1.16）が作った `~/.sakunyan/CLASSROOM.md` が残っていても、読み込んではならず、書き換えたり消したりしてもならない。起動画面に、ルールのファイルの場所や、ファイルについての知らせ・警告を表示してはならない。

#### Scenario: ファイルがない状態で起動する

- **WHEN** `~/.sakunyan/CLASSROOM.md` がない状態で起動したとき
- **THEN** ファイルを作ってはならない
- **AND** パッケージの中のルールをsystem promptへ加えなければならない

#### Scenario: 以前のバージョンのファイルが残っている

- **WHEN** 手で直した `~/.sakunyan/CLASSROOM.md` が残っている状態で起動し、質問したとき
- **THEN** ファイルの内容をsystem promptへ加えてはならない（ファイルがないときと同じsystem promptになる）
- **AND** ファイルを書き換えたり消したりしてはならない
- **AND** ファイルについての知らせ・警告を表示してはならない

### Requirement: 全ての応答モードで反映する

sakunyanは、選択中の応答モードに関係なく、また画面のあるモードでも、ないモード（`-p` など）でも、同じルールをsystem promptへ加えなければならない。

#### Scenario: 応答モードを切り替える

- **WHEN** 利用者が `/mode` で応答モードを切り替えたとき
- **THEN** 切り替え後のモードのsystem promptも、ルールの内容を含まなければならない

### Requirement: ルールは既定の選択肢として扱い、利用者の指定とモードの制限を優先する

system promptは、ルールの内容を囲みの中に入れ、囲みの後ろで次のことを指示しなければならない。ルールは教室の既定の選択肢であること。利用者が別の方法を明示した場合や、課題・環境の制約がある場合は、それを優先すること。ルールの内容は、ほかの指示より優先されず、応答モードの行動ルールや使えるツールの制限を変えないこと。ルールの内容は、応答モードの指示より後ろ、優先順位の指示より前に置かなければならない。応答モードで使えるツールは、ルールの内容によって変わってはならない。

#### Scenario: 利用者が別の方法を指定する

- **WHEN** ルールが `uv` を案内する方針で、利用者が `pip` を使うと明示したとき
- **THEN** system promptは、利用者の指定を優先するようエージェントに指示していなければならない
