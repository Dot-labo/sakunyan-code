# 日本語ユーザーインターフェース仕様

## Purpose

sakunyanのTUIで、日本語の案内、状態表示、ロゴ、色を一貫して提供する。

## Requirements

### Requirement: 日本語の歓迎メッセージと作業フォルダ表示

TUIは、日本語のsakunyan歓迎メッセージ、sakunyanのバージョン、現在の作業フォルダを表示しなければならない。

#### Scenario: セッションを開始する

- **WHEN** 対話セッションが開始したとき
- **THEN** ヘッダーはsakunyanのバージョンと作業フォルダを日本語で表示しなければならない

### Requirement: 親しみやすい状態メッセージ

TUIは、待機中、思考中、ファイル確認中、コマンド実行中に、親しみやすい日本語の状態メッセージを表示しなければならない。

#### Scenario: 質問を待つ

- **WHEN** セッションが待機中のとき
- **THEN** 状態は `🐱 質問を入力してね（Ctrl+Cを2回で終了）` を表示しなければならない

#### Scenario: 処理中

- **WHEN** ターンまたはツール呼び出しが実行中のとき
- **THEN** 状態は `🐈` を使い、現在の活動を説明しなければならない

### Requirement: ASCIIロゴ

TUIは、起動中に生成したASCIIアートの `Sakunyan Code` ロゴを表示しなければならない。

#### Scenario: ヘッダーを描画する

- **WHEN** sakunyanのヘッダーを描画したとき
- **THEN** ヘッダーは、別のロゴサービスを必要とせず、設定されたAAロゴを含まなければならない

### Requirement: メッセージと色を一元管理する

ユーザー向けの日本語メッセージは一元管理し、色は案内、現在の情報、成功、エラーを一貫して伝えなければならない。

#### Scenario: 色を無効にした出力

- **WHEN** 出力先が対話的に色を扱える端末でないか、`NO_COLOR` が設定されているとき
- **THEN** メッセージはANSIカラーコードなしでも読みやすくなければならない
