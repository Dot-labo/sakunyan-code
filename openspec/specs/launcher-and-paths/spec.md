# ランチャーとパス仕様

## Purpose

対象フォルダを明示的に指定してsakunyanを起動し、意図した作業範囲でpiを実行する。

## Requirements

### Requirement: 対象フォルダを明示する

ランチャーは、piを起動する前に対象フォルダの引数を必須としなければならない。

#### Scenario: 対象フォルダがない

- **WHEN** ユーザーが引数なしで `sakunyan` を実行したとき
- **THEN** ランチャーはpiを起動する前に停止し、`sakunyan .` の実行方法を説明しなければならない

### Requirement: 既存のディレクトリを作業フォルダとして使う

ランチャーは対象パスを解決し、それがディレクトリであることを確認し、そのディレクトリへ移動して、そこを作業フォルダとしてpiを起動しなければならない。

#### Scenario: 現在のディレクトリを相対指定する

- **WHEN** ユーザーが既存のフォルダで `sakunyan .` を実行したとき
- **THEN** piはそのフォルダで起動しなければならない

#### Scenario: パスがない

- **WHEN** 対象パスが存在しないとき
- **THEN** ランチャーは停止し、現在のディレクトリ、解決した対象パス、パスの例を表示しなければならない

### Requirement: ホームパスを明示する

ランチャーは、既存のディレクトリに解決できる場合、`~` とホーム相対パスをサポートしなければならない。

#### Scenario: ホームディレクトリ

- **WHEN** ユーザーが `sakunyan ~` を実行したとき
- **THEN** piはユーザーのホームディレクトリで起動しなければならない

### Requirement: 基本オプションをpiの起動前に処理する

ランチャーは、`--` より前にある `-v` / `--version` / `-h` / `--help` を、対象フォルダの有無や位置に関係なくsakunyan自身のオプションとして処理しなければならない。このとき、対象フォルダの検証、piの読み込み、対話画面の起動、ネットワーク接続、APIキーの入力を行ってはならない。

#### Scenario: バージョンを表示する

- **WHEN** ユーザーが `sakunyan --version` または `sakunyan -v` を実行したとき
- **THEN** ランチャーは配布パッケージのバージョンだけを標準出力へ表示し、終了コード0で終了しなければならない

#### Scenario: 使い方を表示する

- **WHEN** ユーザーが `sakunyan --help` または `sakunyan -h` を実行したとき
- **THEN** ランチャーは使い方、対象フォルダの指定例、利用可能なオプションを標準出力へ表示し、終了コード0で終了しなければならない

### Requirement: オプションとパスを区別する

ランチャーは、対象フォルダより前にある不明なオプションを対象フォルダとして扱ってはならず、`--` より後ろの引数をオプションとして解釈してはならない。

#### Scenario: 不明なオプション

- **WHEN** ユーザーが `sakunyan --bogus` のように、対象フォルダより前に不明なオプションを指定したとき
- **THEN** ランチャーはpiを起動せず、不明なオプションであることと `sakunyan --help` の案内を標準エラーへ表示し、終了コード2で終了しなければならない

#### Scenario: `-` で始まるフォルダ名

- **WHEN** ユーザーが `sakunyan -- --my-project` を実行したとき
- **THEN** ランチャーは `--my-project` を対象フォルダとして扱わなければならない

#### Scenario: 対象フォルダより後ろの引数

- **WHEN** 対象フォルダより後ろに追加の引数があるとき
- **THEN** ランチャーは、`--` より前の `-v` / `--version` / `-h` / `--help` を除き、その引数を解釈せずにpiへそのまま渡さなければならない
