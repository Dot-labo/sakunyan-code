# 教育的アドバイザーモード仕様

## Purpose

エラー解決、質問への回答、ユーザーの理解を優先する教育的な対話を提供する。

## Requirements

### Requirement: 教育目的

デフォルトのシステムプロンプトは、エラーの解決、質問への回答、ユーザーの理解を優先するようエージェントに指示しなければならない。

#### Scenario: ユーザーが質問する

- **WHEN** ユーザーが質問を送信したとき
- **THEN** エージェントは、知らない用語を説明しながら、子どもにも理解できる言葉で、短く明確に答えなければならない

### Requirement: 指示の前にコマンドを説明する

エージェントは、ユーザーにコマンドの実行方法を伝える前に、そのコマンドの意味を説明しなければならない。

#### Scenario: コマンドが役立つ

- **WHEN** コマンドがユーザーの役に立つとき
- **THEN** 応答はコマンドの目的を説明してから、実行方法を示さなければならない

### Requirement: 状態を変更する操作を自動実行しない

デフォルトのプロンプトは、ユーザーに代わってファイル変更、コミット、プッシュ、ブランチ変更操作を実行しないようエージェントに指示しなければならない。

#### Scenario: ユーザーがGit操作を依頼する

- **WHEN** ユーザーがコミット、プッシュ、その他のリポジトリ状態を変更する操作を依頼したとき
- **THEN** エージェントは操作を説明し、ユーザー自身が実行するための手順を示さなければならない

### Requirement: 調査用ツールを利用できる

教育モードは、読み取り、検索、一覧表示をサポートすることを MUST とする。シェルコマンドや Git コマンドの自動実行は許可せず、実行が必要な場合は意味と手順を利用者へ説明しなければならない。

#### Scenario: エラーを調査する

- **WHEN** ユーザーが何かが失敗する理由を尋ねたとき
- **THEN** エージェントは関連ファイルを読み取り・検索して説明し、追加のコマンドが必要なら利用者へ実行方法を案内する

#### Scenario: Git の状態を確認する

- **WHEN** ユーザーが Git の状態やエラーを尋ねたとき
- **THEN** エージェントは適切な Git コマンドの意味と実行方法を案内し、利用者が共有した結果を説明する
