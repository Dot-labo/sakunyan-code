# sakunyan

生徒向けにカスタマイズした、pi ベースのコーディングエージェント。初心者がコードを書き、調べ、実行しながら学べることを目的とする。

## 背景

プログラミングを学ぶ生徒にとって、一般的なコーディングエージェントは高機能である一方、導入方法や設定、英語の UI、エラーへの対処が最初の壁になりやすい。また、課金や API キーの準備も、学習を始める前の負担になる。

そこで、既存の pi を基盤として、生徒が自分の環境でスムーズに使い始められる専用の配布物を作る。OpenRouter の API キーは自社ポータルから発行できるようにし、初心者向けの案内・日本語メッセージ・状態表示を sakunyan 側で提供する。

sakunyan は独自のコーディングエージェントを一から作るものではない。pi の会話・ツール実行基盤を利用しつつ、学習用途に必要な設定と UI を組み合わせるホワイトラベル版である。

## プロジェクト概要

```text
生徒の PC（macOS / Windows + Git Bash）
        │
        └─ sakunyan コマンド
             ├─ pi 本体（固定バージョン）
             ├─ sakunyan 拡張機能・設定・テーマ
             ├─ 生徒プロフィール（ローカル）
             └─ OpenRouter（ポータル発行キー）
```

生徒はプロジェクトフォルダで `sakunyan .` のようにパスを指定して起動する。初回やキー未設定時は、ポータルでのキー発行手順を表示したまま入力を待ち、キーが有効になればそのまま会話を開始する。sakunyan はファイル操作やコード実行に対応し、通常画面には初心者でも理解できるよう工夫したかたちで情報を表示する。

## 目的

- pi の機能を活用した、初心者向けのコーディング環境を提供する
- ファイル操作・コード実行・会話を一つのエージェントにまとめる
- UI、メッセージ、案内を日本語中心にして導入のつまずきを減らす
- 通常の pi や他のコーディングエージェントへ移行できる基礎も残す

## 基本方針

- pi 本体はフォークせず、拡張機能・設定・テーマ・ランチャーで実現する
- 最初は `sakunyan` という単一エージェントを提供する
- Plan / Build などの複数モードは、必要になった段階で追加する
- 生徒の会話履歴とプロフィールは、初期段階では PC 内だけに保存する
- Web 検索は必須機能だが、まず基本機能を完成させた後に追加する
- 初心者向けの案内を優先し、終了方法（Ctrl+C）を画面上に明示する

## 対応環境

- Node.js 22.19.0 以上
- macOS
- Windows
  - Git Bash を前提とする
  - pi は bash 環境を必要とするため、Git for Windows の導入を基本とする

## 想定する導入方法

生徒はコマンドで sakunyan を導入し、対象フォルダを明示して起動する。

```sh
sakunyan .
sakunyan ./my-project
sakunyan ~/projects/my-project
sakunyan ~
```

引数がない場合は起動せず、作業したいフォルダへ移動して `sakunyan .` を実行するよう案内する。ホームフォルダも `sakunyan .` または `sakunyan ~` と明示すれば対象にできる。この方針により、生徒が sakunyan の対象範囲を意識できるようにする。

## API キー設定

OpenRouter の API キーは、自社ポータルから生徒が発行する。sakunyan 自体がキーを発行するのではなく、ポータルでの発行方法を案内する。

初回起動時にキーが未設定の場合は終了せず、次のようなセットアップ画面で待機する。

```text
OpenRouter API キーが設定されていません。

1. 自社ポータルにアクセスしてログイン
2. OpenRouter API キーを発行
3. 発行されたキーを下の入力欄に貼り付け

API キーを入力：
Ctrl+C で終了
```

- キー入力はマスク表示する
- 入力後に有効性を確認する
- 無効な場合は日本語で説明して再入力を促す
- 有効になったら確認なしで sakunyan を起動する
- 終了操作を画面上に明示する

キーの具体的な保存先・OS credential store 対応は後続で決定する。

## sakunyan の機能

### MVP に含めるもの

- pi 本体を固定バージョンで利用
- `sakunyan` ランチャー
- OpenRouter への接続
- 運営側が指定するデフォルトモデル
- ファイルの読み取り・作成・編集
- bash によるコードや開発コマンドの実行
- 初心者向けの日本語メッセージ
- 一行の常設ロゴ・状態表示
- 生徒プロフィールファイルの自動作成と読み込み
- macOS / Windows での基本動作確認

### 後から追加するもの

- Web 検索とページ取得
- Plan / Build などのモード切り替え
- プロフィールの自動更新 hooks
- 明示的な profile Skill / コマンド
- サーバーへの共有（明示的な同意を前提とする）
- 対象フォルダ指定案内の改善
- 高度なモデル上書き設定

## モデル方針

sakunyan のデフォルトモデルは運営側が指定する。将来複数エージェントを追加する場合も、エージェントごとにデフォルトモデルを設定できるようにする。

必要な利用者向けには、スラッシュコマンドなどからモデルを上書きできるようにする。ただし通常画面に複雑なモデル選択 UI は表示しない。

## UI 方針

通常画面は会話と最低限の状態表示に絞る。詳細な操作はスラッシュコマンドで行う。

常時表示の例：

```text
🐱 sakunyan | 入力待ち
```

状態表示の例：

- `入力待ち`
- `考え中…`
- `ファイルを確認中…`
- `コマンドを実行中…`
- `接続を確認中…`

pi の標準 UI をすべて翻訳するのではなく、初心者が目にするメッセージや状態表示を優先して日本語化する。

### 色のルール

| 色 | 意味 | 用途 |
|---|---|---|
| シアン | sakunyan の案内 | 見出し |
| 青 | 現在の情報 | 対象フォルダなど |
| 黄 | 利用者が行う操作 | 入力例、次に実行するコマンド |
| 緑 | ウェルカム・成功・準備完了 | 起動時のロゴ、接続成功、保存完了 |
| 赤 | エラー | 存在しないパス、接続失敗 |

色だけで意味を伝えず、見出し、文章、絵文字を併用する。色は対話型ターミナルでのみ表示し、`NO_COLOR` が設定されている場合や出力のリダイレクト時は使用しない。

## プロフィール

生徒ごとに一つのローカルファイルを持つ。内容は厳密な JSON スキーマに固定せず、人間が読める柔軟な形式とする。

記録対象の例：

- 使用 OS や開発環境
- 興味のある分野
- 理解度
- 説明の好み
- 学習中の内容
- 最近の会話から得られた補足メモ

プロジェクト固有の情報は、pi の通常のコンテキスト機能に任せる。プロフィールの更新方法は、明示的な Skill / コマンド、hooks、自動更新などを後から比較して決める。

## Web 検索

Web 検索は最終的に必須とするが、MVP には含めない。

追加時は、専用 API キーを生徒に要求しない簡易検索を優先する。既存の pi パッケージ（例：DuckDuckGo 系の検索・本文抽出パッケージ）を調査し、利用可能なら自前実装より優先する。

## 制約と注意

- pi の拡張機能はユーザー権限で実行される
- pi のツール制御は OS サンドボックスではない
- API キー、プロフィール、会話履歴をログやプロンプトに不要に露出させない
- 外部共有は初期機能に含めない
- npm パッケージに含める pi のバージョンを固定し、更新は検証してから行う
